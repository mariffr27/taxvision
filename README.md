# 📊 TaxVision

**TaxVision** adalah aplikasi berbasis web yang dirancang untuk mendukung pengolahan, visualisasi, dan analisis data perpajakan secara efisien dan intuitif. Project ini dikembangkan sebagai bagian dari tugas akhir (Skripsi).

---

## 📸 Overview Architecture

Sistem ini dibangun menggunakan arsitektur terpisah (*decoupled architecture*) antara sisi client dan server:

* **Frontend:** Menangani antarmuka pengguna (UI), visualisasi grafik, dan interaksi interaktif.
* **Backend:** Menangani logika bisnis, manajemen database, RESTful API, dan pemrosesan data perpajakan.
